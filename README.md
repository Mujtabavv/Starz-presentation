StarZ™ (ستارز) - Feasibility Study Presentation 🍔
An interactive, web-based presentation for the StarZ™ business plan and feasibility study. This project transforms a comprehensive business document into a visually appealing, cinematic, and easy-to-navigate presentation using the Reveal.js framework.
📌 Overview
StarZ™ is a proposed premium fast-food brand based in Khartoum North, Sudan. The business model focuses on "Lean Operations," utilizing a modified 20-foot shipping container to minimize CAPEX while maximizing brand impact through high-quality packaging and a cinematic visual identity.
This presentation covers:
￼ Executive Summary
￼ Brand Identity & Market Positioning
￼ Location & Structural Model
￼ Capital Expenditure (CAPEX)
￼ Operations & Menu Pricing
￼ Unit Economics & Break-Even Analysis
￼ Marketing & Packaging Strategy
✨ Features
￼ RTL Support: Fully optimized for Arabic text using the ⁠Cairo⁠ Google Font.
￼ Dark Mode UI: A high-contrast, cinematic dark theme ⁠#0D0D0D⁠ that aligns with the StarZ brand identity.
￼ Responsive Design: Adapts to different screen sizes and orientations.
￼ Interactive Navigation: Swipe on mobile or use arrow keys on desktop to navigate between slides.
￼ No Build Tools Required: Pure HTML/CSS with CDN-linked libraries.

🚀 How to Run
1. Create a new folder on your computer (e.g., ⁠StarZ_Presentation⁠).
2. Save the HTML code provided into a file named ⁠starz_presentation.html⁠ inside this folder.
3. Move all the downloaded image files into the same folder and ensure their names match the table above perfectly.
4. Double-click the ⁠starz_presentation.html⁠ file to open it in your default web browser (Chrome, Safari, Edge, etc.).
5. Note: An active internet connection is required the first time you load it, as it fetches the Reveal.js library and Google Fonts via CDN.
